# 프로젝트 계획: 공직자 재산 유튜브 쇼츠 자동화

최종 수정: 2026-11-03

## 1. 컨셉

공직자 재산공개 정보를 유튜브 쇼츠(세로, 60초 이내)로 영상과 함께 읽어 준다.

### 영상 구성

1. **인물 소개 (약 8초)**: 대상 인물을 AI 아바타로 모델링해 게임 캐릭터 선택창처럼
   등장시키며 간략히 소개한다.
   예: "00구청장 xxx입니다. 과거 00의원을 지냈고 아버지도 4선 의원인 명문가 집안입니다."
2. **자산 낭독 (본문)**: 부동산, 예금, 주식 등 자산 항목을 차례로 읽는다. 항목이 바뀔 때마다
   그 자산 유형과 규모에 맞는 AI 영상이 재생된다.
   예: 임야 10,000평 → 넓은 밭이 펼쳐지는 영상. 아파트 → 아파트가 건축되며 올라가는 영상.
3. **소감 (채널별 톤)**: 채널 성격에 맞는 코멘트를 덧붙인다.

### 채널 전략

- 채널 2개를 분리 운영한다. 각각 "추대형"(우호적)과 "풍자형" 톤 프리셋을 갖는다.
- 두 채널의 재산 수치와 사실 관계는 동일한 원천 데이터에서 나온다.
- **직접적 인물 비하는 하지 않는다.** 풍자는 인물이 아니라 자산과 상황을 대상으로 한다.
- 허위 사실, 인격 모독 문구는 대본 생성 단계에서 필터링한다.
- 채널 설명에 AI 제작 사실과 편집 관점을 명시하는 것을 권장한다.

### 대상 선정

- 뉴스타파 공직자 재산 DB의 현직 공직자를 임팩트 있는 순서로 다룬다.
- 과거 재산 이력이 있으면 함께 살펴보고 변동 내역을 대본에 반영한다.
- 샘플 인물 페이지: https://jaesan.newstapa.org/people/xbKnL7HJ2knQ-f

- 영상 생성 서비스 최종 선택 (아래 시장조사 참고)

## 3. 시장조사 결과 (2026-11 기준)

### 실제 얼굴 아바타 (인물 소개 장면)

- **HeyGen Avatar IV**: 사진 한 장으로 말하는 아바타. API 종량제, 사진 아바타 분당 약 $3~4.
  쇼츠 인트로 8초 기준 영상당 약 $0.5. 가장 많이 추천됨.
- **Hedra Character-3**: 2위 후보. 상반신 애니메이션 지원.
- **D-ID**: 저가, API 용도.
- 로컬 무료 대안: **LatentSync**(ByteDance, Apache 2.0), **LivePortrait**. GPU 필요.
  품질과 속도는 유료 서비스보다 낮음.

### 자산별 AI 영상

| 서비스 | 초당 비용 | 비고 |
|---|---|---|
| Veo 3.1 Lite (Google) | $0.05 (720p) | 대형사 중 최저가, 오디오 포함 |
| Runway Gen-4 Turbo | $0.05 | |
| Kling | $0.07~0.10 | 출처마다 다름 |
| Wan (Alibaba) | $0.05~0.20 | 해상도별 |
| Sora | 제외 | API 2026-09 종료 |

**전략**: 자산 유형·규모별 템플릿 클립을 한 번만 생성해 라이브러리로 재사용한다.
예: "아파트 1채", "아파트 3채 이상", "임야 소규모", "임야 대규모", "예금 1억 미만" 등 30~50개.
매번 새로 생성하면 영상당 $2~3, 재사용하면 추가 비용 거의 0.

### 한국어 TTS

- **클로바 더빙**: 한국어 품질 최고, 숫자 읽기 정확. 무료는 비상업용만 → 유료 플랜 필요.
- **타입캐스트**: 감정 연기에 강함. 두 채널의 톤 차이를 목소리로 내기에 적합.
- **수퍼톤**: 쇼츠 나레이션 가성비, 월 약 $3.
- ElevenLabs: 한국어 발음 약함, 제외 권장.

## 4. 법적·정책적 제약 (반드시 지킬 것)

### 유튜브 정책

- 2025-07부터 "비진정성 콘텐츠(inauthentic content)" 정책: 대량 생산 템플릿형 영상은
  수익화 제외, 반복 시 채널 삭제. 2026-07 명시된 세 범주 중 "AI 페르소나가 금융 등
  민감 주제를 논하는 것"이 이 프로젝트와 가장 가깝다.
  → 영상마다 고유한 해설을 넣고, 완전 자동 양산을 피한다.
- 실제 인물의 얼굴·목소리를 AI로 만든 영상은 업로드 시 "변경 또는 합성 콘텐츠" 체크 의무.
- 당사자가 개인정보 삭제 요청을 하면 유튜브가 영상을 내릴 수 있다.

### 공직선거법 제82조의8

- 선거일 90일 전부터 선거일까지: AI 딥페이크 영상을 이용한 선거운동 전면 금지
  (AI 표시 여부와 무관). 위반 시 최대 징역 7년.
- 그 외 기간: AI 생성물임을 명확히 표시해야 함. 미표시 시 과태료 최대 1,000만원.
- → 파이프라인에 선거 일정 기반 자동 중단 스위치를 넣는다.

### 명예훼손

- 한국은 사실 적시 명예훼손도 처벌 대상(형법 307조, 정보통신망법 70조).
- 공개된 재산 수치를 그대로 읽는 것은 공익 목적 보도에 해당하나, 인물에 대한
  부정적 평가 문구는 위험. → 인물 비하 금지 원칙의 근거.

### 데이터 출처

- 뉴스타파 사이트의 이용약관·데이터 라이선스는 아직 확인하지 못함 (네트워크 차단).
  크롤링 전에 robots.txt와 약관을 확인하고, 필요하면 원천인 관보·공직윤리시스템(peti.go.kr)을
  사용한다.

## 5. 클라우드 세션 환경 메모

- 클라우드 세션의 기본 네트워크 정책은 jaesan.newstapa.org 접속을 차단한다.
- 해결: claude.ai/code → 환경(Default) → Edit → Network access를 "Full"로 변경 → 새 세션 시작.
  안내: https://code.claude.com/docs/en/cloud-environments#network-access
- 2026-11-02 세션에서 두 경로(curl, WebFetch) 모두 실패 확인.
